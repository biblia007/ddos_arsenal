ОПИСАНИЕ
================================================================================

DDOS ARSENAL – многофункциональный инструмент для кибербезопасности,
объединяющий DDoS-атаки (12+ методов), OSINT-разведку, сканирование портов,
анализ веб-сайтов, поиск поддоменов и социальных профилей.
Включает 24 функции в одном интерфейсе с поддержкой прокси и 12 цветовых схем.

1. DDoS-АТАКИ (12+ МЕТОДОВ):

УСТАНОВКА
================================================================================

СПОСОБ 1: АВТОМАТИЧЕСКАЯ (РЕКОМЕНДУЕТСЯ)

  1. Скачайте файл ddos_arsenal.py
  2. Запустите в терминале:
     python ddos_arsenal.py
  3. Программа автоматически установит все необходимые библиотеки

СПОСОБ 2: РУЧНАЯ

  1. Установите Python 3.8+
  2. Установите библиотеки:
     pip install requests colorama dnspython python-whois tldextract
     pip install pyOpenSSL cryptography urllib3 certifi charset-normalizer
     pip install idna six json5 beautifulsoup4 lxml html5lib
     pip install geopy pytz tqdm rich prettytable tabulate termcolor
     pip install click python-dotenv
  3. Запустите:
     python ddos_arsenal.py
